=== 6.4 (cat 6) route=/
Q: Tell me about Refract
A [81w]: Refract is a research workspace that keeps reading, evidence, recall, and statistics connected in one session. Researchers ask questions about their papers and get answers that show the exact paper and page behind each claim, so verifying a source takes one step. Learners answer and rate their confidence before seeing the source, which means the tool measures what they actually know. Refract uses retrieval-augmented generation (RAG) over the researcher's own papers, and Neerav built it from research on how people learn.
   show project.refract-ai — Refract: case study (Research and learning platform)
Q: What was hard about building it?
A [93w]: The hardest early problem was keeping the research session intact. The first version let the document and session state drift apart, so a workspace could quietly work on a different set of sources. Neerav fixed this by giving each session a persisted identity and recovery for older records, then browser tests confirmed that navigation and reload kept the intended sources. The second hard problem was recall: passive highlighting made it too easy to mistake recognition for real memory, so Review now asks for an answer and a confidence rating before revealing the source.
   show project.refract-ai.methodology — Refract: build, evidence, and scope
Q: Who would use it?
A [76w]: Refract is built for researchers who work across papers, notes, and data, and for learners who need to retain what they read. A researcher can ask questions of their own papers and see the exact page behind each answer, using retrieval-augmented generation (RAG). Learners use its recall review, where they answer and rate their confidence before seeing the source. Anyone running statistical analysis can have a person check the data before a model result is accepted.
   show project.refract-ai.13-refract-reduces-reconstruction — Refract reduces reconstruction work across learning, research review, and applied analysis
